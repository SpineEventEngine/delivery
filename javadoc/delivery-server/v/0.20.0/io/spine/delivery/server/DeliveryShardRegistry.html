Package io.spine.delivery.server

Class DeliveryShardRegistry

  • All Implemented Interfaces:
    io.spine.logging.WithLogging 
    
public final class DeliveryShardRegistry
 implements WithLogging

    The registry of the shard indexes along with the worker identifiers, which process the messages corresponding to each index.

    The session records are kept in a ShardSessionStore, which several Delivery servers may share. Every read-then-write of a record is a compare-and-set against the record that was read, so each change is atomic across all those servers.

      • DeliveryShardRegistry

        DeliveryShardRegistry(ShardSessionStore store, Duration processingTimeout)

        Creates a new DeliveryShardRegistry backed by the given store.

        The given processingTimeout is used to determine whether a session is stale. Stale sessions are released automatically. Pass Durations.ZERO to disable the stale-check. In this case all picked up sessions will always be considered active until explicitly released by a worker.

    • Method Detail

      • pickUp

         ShardProcessingSession pickUp(ShardIndex index, WorkerId worker)

        Picks up the shard at a given index to process.

        This action is exclusive across all the servers that share the store, with the exception below: a single shard may be served by a single worker at a given moment of time.

        In case of a successful operation, an instance of ShardProcessingSession is returned. There are two options when it is successful:

        • There is no worker associated with the requested shard.
        • The requested shard is already being processed by some worker, but its processing time reached processingTimeout. Such a session is considered stale and released automatically.

        In case the shard at a given index is already picked up by a worker and has not reached processing timeout, an ShardAlreadyPickedUp is thrown.

        The exclusivity has one exception: a store shared by servers that a network split divides may let each part of them pick the same shard.

        Parameters:
        index - the index of the shard to pick up for processing
        worker - the identifier of the worker for which to pick the shard
        Returns:

        the session of shard processing

      • releaseInactiveSessions

         ImmutableSet<ShardSessionRecord> releaseInactiveSessions(Duration inactivityPeriod)

        Clears up the recorded WorkerIds from the session records if there was no activity for longer than the passed inactivityPeriod.

        It may be handy if an instance of the application hangs or gets killed, so that it is not able to complete the session in a conventional way.

        Returns:

        the released records as they were before the release, each reported by the only call whose write released it
