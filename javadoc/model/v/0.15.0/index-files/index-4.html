DeliveryPickUpOutcome - class in io.spine.delivery 
An outcome of the shard pick-up attempt.

This is a Delivery-internal type that is created as a counterpart of `PickUpOutcome` introduced in
`spine-core` in version `1.9.x`. Delivery servers are already using the core library `2.0.x`
that doesn't have this type yet. That's why this counterpart helps to connect Delivery servers
that use core `2.0.x` and Delivery clients that are on core `1.9.x`.
