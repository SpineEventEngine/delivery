subscribeToShardUpdates(com.google.protobuf.Empty) - function in io.spine.delivery.admin.grpc.AdminServiceGrpc.AdminServiceBlockingStub 
Subscribes to the updates of shard info.
The first received `SubscriptionResponse` is an acknowledgement of a successfully created
subscription and contains only the `created` field set. All other responses contain
`ShardInfoUpdate`. It is guaranteed that the acknowledgement is sent only once as a first
response and never repeated again. Also, it is impossible that any update comes
before the acknowledgement.
Users should consider the subscription as created only after receiving the acknowledgement
in the `SubscriptionResponse`. All changes in the system occurred before the subscription
acknowledgement are not tracked by this call.
Each update is sent as a single `ShardInfoUpdate`.
