StoredShardSession - class in io.spine.delivery.storage 
The form in which the Redis and Hazelcast stores keep the session record of a shard.

Next to the record, it keeps the ID of the write that stored the record. A writer that did
not learn the outcome of its write tells by that ID whether the record it finds is its own,
even when another write stored an equal record.
