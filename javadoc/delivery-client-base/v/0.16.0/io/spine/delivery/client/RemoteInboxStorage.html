Package io.spine.delivery.client

Class RemoteInboxStorage

  • All Implemented Interfaces:
    io.spine.logging.WithLogging , io.spine.server.Closeable , io.spine.server.storage.Storage , java.io.Closeable , java.lang.AutoCloseable 
    
public final class RemoteInboxStorage
extends InboxStorage implements WithLogging

    An InboxStorage based on a remotely stored Inbox state.

    The read and write operations invoked by the framework are overridden to run through the gRPC client of the Delivery server. The removal operations, which InboxStorage routes through its underlying record storage, are served by a gRPC-backed record storage created by the package-private RemoteStorageFactory.
