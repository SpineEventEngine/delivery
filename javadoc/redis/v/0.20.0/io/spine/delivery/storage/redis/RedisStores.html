Class RedisStores

  • All Implemented Interfaces:
    java.lang.AutoCloseable 
    
public final class RedisStores
 implements AutoCloseable

    The inbox and session stores that share one connection to Redis.

    All the processes connected to the same Redis database read and write the same data, and hear about the changes made by each other.
