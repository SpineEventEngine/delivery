FilteringObserver

class FilteringObserver : ServerCallStreamObserver<SubscriptionResponse>

Filters out updates that were sent before the response had been acknowledged.

This observer guarantees that the SubscriptionResponse acknowledging the subscription arrives first. All the updates that may be posted before acknowledging the response are omitted by this observer.
