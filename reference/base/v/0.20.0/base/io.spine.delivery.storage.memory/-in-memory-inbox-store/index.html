InMemoryInboxStore

class InMemoryInboxStore : InboxStore(source)

An InboxStore that keeps the messages in the memory of the process.

The messages of each shard are kept in a ShardInbox, locked on its own, so operations on different shards never wait for each other. The inbox of a shard is created on the first write to the shard, and is never removed, so a write never races with a removal.

The stored messages are the written objects themselves, and reads return them as they are, which is safe because Protobuf messages are immutable.
