ShardSessionStore

interface ShardSessionStore : AutoCloseable(source)

Stores the session records of shards: which worker processes a shard, and since when.

The only way to write a record is compareAndSet, which writes it only if the stored record has not changed since it was read. So when several processes share the store, no two of them can change a record based on the same stored value.

Each record is stored with the ID of the write that stored it. A writer that did not learn the outcome of its write tells by that ID whether the record it finds is its own, even when another writer stored an equal record.
